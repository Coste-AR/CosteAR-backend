# Bitácora — issue #293: capa LLMService provider-agnóstica

## Qué se hizo

- Interfaz `LLMService` con `completeJSON<T>(system, user, opts?)` que **nunca lanza** (null ante
  error). `opts`: `schema?` (Zod), `cacheSystem?` (prompt caching de Anthropic), `maxTokens?`.
- `AnthropicLLMService` — usa el **Vercel AI SDK** (`ai@7` + `@ai-sdk/anthropic@4`).
  `generateObject` cuando hay schema, `generateText` + `extractJson` cuando no. `cacheSystem`
  agrega `providerOptions.anthropic.cacheControl`.
- `GroqLLMService` — adaptador fino sobre el `GroqService` actual. Ignora `cacheSystem`; si vino
  `schema`, valida la respuesta con él.
- `getLLMService(useCase)` — factory por caso de uso (`vault_query | advisor | context | classifier`).
  Anthropic por default para los tres primeros, Groq para el clasificador. **Sin
  `ANTHROPIC_API_KEY` válida cae a Groq y lo registra una vez** (degradación segura).
- `env.ts`: `ANTHROPIC_API_KEY`, `LLM_PROVIDER_*` (enum anthropic|groq), `LLM_MODEL_ANTHROPIC_*`.
  Todos con default → no rompen el arranque.
- Deps nuevas: `ai`, `@ai-sdk/anthropic` (10 paquetes).

## Decisiones

- **AI SDK en vez de un wrapper propio** sobre `@anthropic-ai/sdk` + `groq-sdk` — recomendación de
  `herramientas-a-evaluar.md` §2: `generateObject` con Zod, caching por `providerOptions`, y
  telemetría OTel casi gratis, con menos código propio.
- **`GroqService` no se renombró a `groq-llm.ts`**: lo importan varios consumidores. En vez de
  eso, `GroqLLMService` lo envuelve. `transcribeAudio` (Whisper) sigue en `GroqService` directo,
  no pasa por `LLMService`.
- **AI SDK v7 no acepta system como mensaje** ("System messages are not allowed... Use the
  `instructions` option"): se pasa `system` como parámetro y el `providerOptions` a nivel de
  llamada. La semántica exacta del caching se afina en F1-10, con una key real.
- Los IDs de modelo son env-configurables (`claude-sonnet-4-5` / `claude-haiku-4-5` por default)
  para no atarlos al código.

## Fuera de alcance

Migrar `vault-query-service` y `advisor-service` a `LLMService` (#301, F1-10). El clasificador
(Fase 2). Medir costo/latencia reales (necesita `ANTHROPIC_API_KEY`).
