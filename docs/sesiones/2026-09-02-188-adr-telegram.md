# Bitácora — issue #188: ADR Telegram

## Decisión documentada

El ADR acepta Telegram como canal propio y reversible. No se asume que las
personas operativas lo adopten: eso queda como validación del piloto.

## Plan B y preguntas abiertas

Si no hay adopción, el plan B es el reenvío desde el bot existente hacia el
punto de ingesta común. Quedaron como preguntas abiertas la disponibilidad de
Telegram, el comportamiento y mantenimiento del bot existente, y la preferencia
por un canal separado.

## Alcance

Este issue modifica únicamente el ADR y su bitácora; no cambia código ni datos.
