# Bitácora — issue #196: depósito

El nivel y el umbral se expresan en la unidad física del material, no como
porcentaje de capacidad. La capacidad de almacenamiento se documenta en una
unidad de cantidad (por ejemplo, bushels), y los movimientos se reconcilian
directamente en esa unidad. Se puede derivar un porcentaje para una pantalla
posterior, pero no es el contrato ni la alerta de este issue.

El umbral vive en cada depósito porque la tabla existente de reglas de alerta
no puede asociarse a un depósito; la alerta derivada se activa cuando el nivel
es menor o igual a ese umbral. Quedan fuera consumo teórico/real y motor de
costos.
