# Contribución marginal

La **contribución marginal** de un producto es su precio de venta unitario menos su costo
variable unitario. Representa cuánto aporta cada unidad vendida a cubrir los costos fijos y, una
vez cubiertos, a la ganancia.

## Fórmula

`contribución marginal unitaria = precio de venta unitario − costo variable unitario`

La **contribución marginal total** de un período es la contribución unitaria multiplicada por las
unidades vendidas.

## Ratio de contribución marginal

El **ratio** o razón de contribución marginal es la contribución marginal dividida por el precio
de venta. Indica qué proporción de cada peso de venta queda disponible para cubrir costos fijos.

## Costos semifijos

Un costo **semifijo** (o mixto) tiene una parte fija y una parte variable. Para calcular la
contribución marginal hay que separar ambas partes: solo la porción variable se resta del precio.
Si no se conoce el tramo variable, la contribución no puede calcularse con precisión y el caso
queda incompleto.
